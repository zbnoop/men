# M1.7 Fluent 原始产物

`final/` contains the Fluent 2026 R1 DEMO case/data files, transcripts, native heat-transfer reports and UDF CSV files produced by the journals in the parent directory. `diagnostic_diffusion_yes/` and `diagnostic_no_diffusion_hang/` preserve the two real setup/energy-audit diagnostics described in `docs/11_Codex_M1.7验证报告.md`.

The binary case/data files are intentionally kept as raw solver outputs. They are not formal 7050 reproduction results; all material values are the isolated DEMO values stated in the report.
