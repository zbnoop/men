# M2 三维熔铝炉参数化建模方案与缺失数据清单

本文件是 M1.7 热流方向、界面连续性和末时间步能量闭合通过后的下一步方案。这里只制定建模合同和验收门，不运行完整炉膛瞬态，也不运行参数优化。

## 1. 建模原则

1. 保留 `amf-fluent2026` 分支；不修改 `main`。
2. SpaceClaim/Workbench 使用参数化几何和命名选择，不把演示尺寸直接升级为论文尺寸。
3. 继续使用 `Fluid Zone`、`Solid Zone`、`Coupled Wall` 的清晰分区；正式模型须为每个入口、出口、料块外表面、炉壁和界面建立稳定名称。
4. 先做几何/网格 gate，再做 Fluent 物性/边界 gate，最后才允许短时热传递验证；不在缺失数据时补造参数。
5. M1.7 DEMO 物性只用于回归测试，不能进入 7050 正式 case。

## 2. 三维分区与命名合同

建议的最小区域：

- `furnace_fluid`：炉膛气体域；
- `charge_solid`：铝料/料块固体域，可按料块或连续料床分区；
- `furnace_wall_solid`：若需要解析炉壁导热的固体域；
- `gas_inlet_<id>`、`gas_outlet_<id>`：所有入口和出口独立命名；
- `charge_interface_<id>_fluid` / `charge_interface_<id>_solid`：每个气固界面成对命名；
- `wall_hot_side`、`wall_cold_side`、`symmetry_<id>`：按实际边界启用，不预设不存在的对称面。

网格路线沿用已验证的 ANSYS 2026 R1 MultiZone/Sweep 六面体优先流程：SpaceClaim 先做可扫掠分区，Workbench Meshing 生成多区域匹配界面，再在 Fluent 中进行质量、连接关系、界面热流和守恒验收。MultiZone 配置完成不等同于网格验证完成。

## 4. M2 分阶段执行顺序

### M2-A：数据锁定

建立 `docs/` 物性与几何台账，给每个量标注 `paper`、`derived`、`demo_only`、`unknown` 或 `conflict`。任何未知量都不得进入正式生产 UDF 或论文复现 case。

### M2-B：三维参数化几何

用参数表驱动 SpaceClaim：炉膛包络、料块/料床、入口/出口、炉壁厚度、可选对称面。脚本输出后做体积、面积、分区连接和命名检查；没有真实尺寸时只生成参数接口，不生成“看似完整”的炉膛。

### M2-C：MultiZone/Sweep 网格 gate

至少建立粗/中/细三档六面体优先网格。验收内容包括负体积、最大 skewness、orthogonal quality、界面匹配、边界名称、区域 cell count 和网格独立性趋势。通过前不进行燃烧、辐射或全炉膛瞬态。

### M2-D：Fluent 物理 gate

先用不含燃烧/辐射的气体→铝料 CHT 复现 M1.7 的界面符号和能量定义，再单独打开辐射，再单独评估燃烧耦合。每次只改变一个物理层，并保存 case/data、journal、transcript 和报告定义。

### M2-E：正式论文复现 gate

仅当 7050 物性来源、几何尺寸、边界工况和网格/时间步收敛均有证据时，才解除生产 UDF 门禁。参数优化必须在该 gate 之后另行批准，不属于当前 M2 方案。

## 5. 当前阻塞数据

- 论文炉膛三维尺寸、壁层结构和 CAD 基准；
- 铝料真实几何/装料量/堆积与接触关系；
- 入口/出口和热气源的空间布置、温度流量程序、压力；
- 7050 合金 `rho(T)`、`cp(T)`、`k(T)`、固相线、液相线和潜热的可追溯来源；
- 气体组分及是否需要燃烧化学反应；
- 炉壁/料面发射率、外侧换热和环境温度；
- 正式网格尺度、近壁目标、时间步长和收敛标准。

在这些数据到齐前，不运行完整炉膛瞬态，也不生成 20 组参数优化结果。
