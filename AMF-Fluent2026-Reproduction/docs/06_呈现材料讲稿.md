# 项目汇报讲稿

1. **研究目标**：复现 Qiu et al. 2018 年矩形蓄热式铝熔化炉，先复现基准工况，再评估参数优化。
2. **核心耦合架构**：炉气流场/燃烧/P1辐射 → Coupled Wall → 7050铝固定Solid Zone（只导热）→ 等效Cp UDF和液相率后处理。
3. **关键方程**：Ts=748K，Tl=911K；两相区 cp=(cs+cl)/2+L/(Tl−Ts)，k为固/液线性插值，f_l=clip((T−Ts)/(Tl−Ts),0,1)。焓需对cp积分。
4. **论文已知与缺失**：已知湍流、辐射、代表性反应、氧化层、入口基准值、10s、约899200网格；缺真实热物性、完整几何、换向时序和反应细节。
5. **实施里程碑**：M0 审计→M1 UDF→M2 CAD/网格→M3气侧→M4 CHT→M5换向→M6基准→M7优化。
6. **目标和限制**：与论文6.29h、68.25 Nm³/t、9.45%对照；区分示例、估算、真实计算、验证结果；迄今不宣称已完成CFD。
7. **需用户输入**：CAD/炉尺寸、7050热物性、换向参数、Fluent版本子版本/许可证/算力。
