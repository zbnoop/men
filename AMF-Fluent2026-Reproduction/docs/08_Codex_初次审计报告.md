## 2. M0 论文模型审计

### 2.1 已核对的 `paper` 事实

- 对象是矩形蓄热式铝熔化炉，论文采用三维非结构有限体积模型；约 899,200 个单元，时间步长 10 s，压力-速度耦合使用 SIMPLE，插值采用一阶迎风（PDF p2）。
- 铝内部只考虑导热，忽略熔融铝流动；炉气与铝料界面进行流固热耦合（PDF p2）。这与本项目 A 路线“炉气 Fluid Zone + 固定铝 Solid Zone + Coupled Wall”一致，但并不等于已经有可运行的 Fluent case。
- 湍流模型为标准 `k-epsilon`；辐射模型为 P1；燃烧采用天然气组分和有限反应速率/涡耗散相关模型（PDF pp2-4）。
- 铝料表面氧化层：厚度 5 mm、孔隙率 20%、表面发射率 0.33；炉膛外壁绝热、内壁发射率约 0.8（PDF p2、p4）。氧化层的导热率、密度、比热及是否随熔化动态变化未给出。
- 固相线 `Ts=748 K`、液相线 `Tl=911 K`；铝初温 300 K，炉温初温 1000 K（PDF p4）。因此温区宽度 `Tl-Ts=163 K` 是 `derived`。
- 导热率公式 (4)：固相 235 W/(m K)，液相 62.8 W/(m K)，两相区线性插值（PDF p3）。
- 等效比热公式 (7)：固相使用 `cs(T)`，液相使用 `cl(T)`，两相区使用平均显热比热加 `L/(Tl-Ts)`（PDF p3）。论文没有给出本项目所需的 7050 合金 `cs(T)`、`cl(T)` 或 `L` 数值。
- 液相率公式 (19)：`f=0`（`T<=Ts`）、`(T-Ts)/(Tl-Ts)`（两相区）、`1`（`T>=Tl`）（PDF p5）。这是温度后处理定义，不应称为 Fluent 内置熔化模型结果。
- 一次风约 0.0739 kg/s、300 K；二次风约 1.4041 kg/s、773 K；设计过量空气系数约 1.05；辅助烟道/主烟道出口流量比例为 0.2/0.8（PDF p4）。
- 论文 Table 1 天然气组分已与仓库 `data/table1_natural_gas_composition.csv` 核对，体积分数合计 100%。
- Table 2 的五个因素及水平已与仓库 CSV 核对：预热温度 300-700 degC、燃气流量 600-1000 Nm3/h、烧嘴高度 1400-2300 mm、倾角 5-25 deg、水平间距 1000-2800 mm。
- Table 3 的 N1-N20 及设计条件已与仓库 `data/table3_20_cases.csv` 核对；Table 5 的非优化/优化条件已与 `data/table5_baseline_optimized.csv` 核对。
- 论文正文报告完全熔化约 22640 s（PDF p5）；Table 5 的 6.29 h 换算为 22644 s，为四舍五入差异，属于 `derived` 一致性检查，不是一次 Fluent 复现结果。

### 2.2 可推导但不能当作输入的内容

- 式 (7) 两相区的等效比热可写成
  `ceq=(cs+cl)/2 + L/163`；但在 `cs`、`cl`、`L` 未确认前只能作为算法形式。
- 式 (18) 的初始最大燃气流量明确写成“每个烧嘴 400 Nm3/h”，并按液相率分段为 100%、线性下降、30%。这只能证明燃料反馈的控制形式；不能自行把它解释为整炉总流量。
- 表 3 设计行的 `U=400` 与式 (18) 的“每个烧嘴 400”数值相同，但两者的系统边界/总量关系没有在论文中完全说明。
- 根据 Table 3 数据直接计算，响应量范围大致为：`Y1=4.11-11.25 h`、`Y2=57.665-110.13 Nm3/t-Al`、`Y3=6.315-14.1387%`。这些是由表中已有数字得到的审计辅助范围，不替代 Table 4。

### 2.3 已确认的 `conflict`

1. **燃气流量 400/800 冲突**：Table 3 的设计条件为 `U=400`，Table 5 的非优化条件为 `U=800`；式 (18) 又把每个烧嘴的初始最大流量写成 400 Nm3/h。论文没有足够信息证明 400 是单烧嘴值、总量值或另一种工况定义。仓库保留该冲突，没有静默改为单一数值。
2. **Table 3 单位冲突**：Table 3 表头印为 `U/Nm3/s`，但正文式 (18) 明确解释 `Nm3/h` 是标准状态下天然气体积流量，Table 2、Table 4、Table 5 也使用 `Nm3/h`。本报告把它标为原文表头疑点，不进行单位换算或“修复”。
3. **Table 4 参数错列/数值不一致**：PDF Table 4 将 `B` 行列为 4.11-11.25，将 `Y1` 行列为 6.32-14.14，并出现 `Y2=6.32-14.14`、`Y3=60.06-110.13`。这些范围与 Table 3 的因素/响应范围明显不匹配。仓库的 `docs/03_论文疑点与输入缺口.md` 已提示该问题，本轮确认后仍保留为 `conflict`，没有编造“正确列序”。
4. **公式编号转录疑点**：PDF p5 的段落文字曾把液相率称为 Eq. (17)，但同页显示的分段液相率公式编号为 (19)；本项目以显示公式 (19) 为准，并将文字编号视为排版/引用疑点。

## 4. M1 等效比热容 UDF 审计

### 4.1 代码检查结果

已检查 `udf/aluminum_equivalent_cp.c` 与 `udf/aluminum_params.h`：

- `aluminum_cp_value(T)` 的三段分支与式 (7) 形式一致，且 `Ts/Tl` 采用闭区间边界：`T<=Ts` 返回固相比热，`T>=Tl` 返回液相比热。
- `aluminum_integrated_h(T)` 对三段比热作分段积分；`DEFINE_SPECIFIC_HEAT` 返回 `h(T)-h(Tref)`，因此焓差与参考温度一致。
- 两相区焓增为 `[(cs+cl)/2]*163 + L`，潜热项被完整计入；代码没有把液相率后处理误用为 Fluent 内置熔化模型。
- `aluminum_k_value(T)` 按式 (4) 在两相区线性插值，并在 `Ts/Tl` 外使用对应相的常数值。
- `aluminum_fraction_value(T)` 与式 (19) 一致，但它是辅助/后处理量，不是 `DEFINE_SPECIFIC_HEAT` 的替代物。
- 未确认的 `AL_CP_SOLID=900`、`AL_CP_LIQUID=1100`、`AL_LATENT_HEAT=390000` 仍被明确标为 `demo_only`；`#ifndef ALLOW_DEMO_MATERIAL` 生产编译防护保持有效。不得将这些数值写成论文物性。
