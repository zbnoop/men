# 分阶段复现计划（约 4–8 周，实际受 CAD、Fluent 环境与算力制约）

| 阶段 | 任务 | 交付物与关卡 |
|---|---|---|
| M0 / 1–3天 | 源文审计、物性与单位核对、几何缺口梳理 | 参数账本、冲突表、阻塞项 |
| M1 / 2–4天 | cp(T)与焓积分 UDF、热导率、液相率后处理 | C 单测、1D 瞬态传热基准设计、能量守恒检查 |
| M2 / 3–7天 | 炉气、烧嘴、烟道、铝料、氧化层 CAD 与网格 | 接触面/Shadow 校核、网格质量、网格独立性计划 |
| M3 / 3–7天 | 冷流→有限速率/EDM燃烧→P1辐射 | 反应元素平衡、烟气温度及残差/热量检查 |
| M4 / 2–5天 | Coupled Wall 与等效比热容，先无潜热后有潜热 | 界面热流守恒、整体焓差与输入热量匹配 |
| M5 / 4–10天 | 蓄热烧嘴周期换向，燃料随熔化率更新 | 多个换向周期验证、换向日志、瞬态算例 |
| M6 / 3–7天 | 对照图7/8/10/11/12与表5的基准 | 熔化时间、温度、热流、液相率误差报告 |
| M7 / 5–15天 | 表3的20组计算与RSM多目标优化 | 完整设计矩阵、可复算拟合、最优点验证 |

顺序不可颠倒。每阶段保留计算输入、代码版本、截图/导出表、运行日志、参考值和偏差说明；未完成不得标记通过。先采用简化铝块1D加热验证，再逐步叠加燃烧、辐射、CHT、动态边界。
