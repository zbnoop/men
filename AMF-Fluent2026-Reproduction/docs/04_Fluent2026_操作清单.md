# Fluent 2026 A路线操作清单

1. 在 CAD 中建立炉气容积及铝料体积，必要时显式5mm氧化层；相邻体共享拓扑或创建适当 Mesh Interface。
2. Fluent Pressure-Based + Transient；开启 Energy。气体区依次验证 Standard k–ε、Species Transport/体积反应/有限速率-涡耗散、P1 Radiation。
3. 固定金属域为 Solid Zone，并赋予7050材料；只解热传导。**不启用**内置 Solidification/Melting（避免与 UDF 潜热重复）。
4. 在 Materials/Solid 中挂接编译后的 DEFINE_SPECIFIC_HEAT 和 DEFINE_PROPERTY。未核实真实热物性前保护宏禁止真实编译。
5. 气/固共形壁面使用 Coupled 热边界并核对 wall/shadow；非共形先创建正确 Mesh Interface。不要同时设定固定温度或固定热通量。
6. 炉墙外边界绝热，内部发射率0.8；氧化层发射率0.33。注意P1壁面参数与炉膛辐射设置一致。
7. 初始化炉气1000K，Patch铝料300K；基准瞬态10s是论文设置，不代表可以不做时间步敏感性检查。
8. 液相率后处理：f_l=0 (T≤748K)，(T−748K)/163K (748<T<911K)，1 (T≥911K)。质量加权平均可得到整体熔化率。
9. 检查壁面净热流/整体铝焓量；再写换向和供气反馈控制，逐步复现论文。
10. 后处理温度、热流、液相率、熔化时间和 RSD，并生成量化误差对照。

所有实际菜单、表达式变量、Scheme/TUI API 需在用户安装的 Fluent 2026 上核对；此文档是操作设计，不是已运行记录。
