# 模型与数据来源（以 Qiu et al. 2018 论文为准）

论文 DOI: 10.1016/j.applthermaleng.2018.09.060。源 PDF 因公开仓库权限与版权限制不收录；以下为研究笔记/数据摘录，须持有原文时再次核验。

- PDF p2 §2.2：铝料内部只考虑导热，忽略液态铝流动；炉气/铝料界面作热耦合。
- p2 §2.2.1 标准 k–epsilon；§2.2.4 p3 P1 辐射；§2.2.5 p4 有限反应速率/EDM（天然气代表性组分及四步简化反应）。
- p3 式(4)：固相热导率 235 W/(m·K)，液相 62.8 W/(m·K)，两相区线性插值。
- p3 式(7)：等效比热法，T≤Ts 时 cp=cs，Ts<T<Tl 时 cp=(cs+cl)/2+L/(Tl−Ts)，T≥Tl 时 cp=cl。真实 cs(T)、cl(T)、L 数值需要另行可靠来源。
- p4 §2.3.5：7050 固相线 Ts=748 K，液相线 Tl=911 K；铝初温 300 K，炉温初始 1000 K。
- p5 式(19)：f_l(T)=0 / (T−748)/163 / 1，分段截断。
- p4 §2.3：一次风约 0.0739 kg/s，300 K；二次风约 1.4041 kg/s，773 K；空气过量系数约1.05；出口主/辅烟道分配比例约 0.8/0.2。
- 氧化层：厚度5mm、孔隙率20%、表面发射率0.33；炉内壁发射率0.8；外壁绝热。
- p2：总单元约899200，时间步长10s，FVM/SIMPLE/一阶迎风。
- p4 式(18)：燃气流量系数phi由液相率控制：f≤0.05 时phi=1，0.05<f<0.5时phi=1−0.7*(f−0.05)/0.45，f≥0.5时phi=0.3。
- p5 §3.2：模拟完成熔化时间约22640s（约6.29h）。
- 论文 Table 3 的设计 U=400 和 Table 5 的设计 U=800 存在冲突；单位亦待核。不要默默校正。
- Table 5 基准：6.29h，68.25 Nm³/t-Al，铝温RSD 9.45%；优化：5.25h，59.83 Nm³/t-Al，铝温RSD 10.01%。
